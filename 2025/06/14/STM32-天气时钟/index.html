工程模板搭建-来自天气时钟

  1. SDK Library （官方网站下载）

    SDK: Software Development Kit的缩写，译软件开发工具包，

    包含外设驱动库，CMSIS：arm官方提供的一套标准接口和内核访问文件

  2. 搭建工程

    工程名为母文件夹

  3. 通过μvision创建项目，调整设置，导入配置

    创建项目，选定芯片

    进入文件拓展页面

    修改项目目标名（Project Targets里），创建子文件夹（Groups里），

    导入文件

    \app\main.c，

    \firmware\cmsis\core\core_cm3.c，

    \firmware\cmsis\device 的 system_stm32f10x.c 、stm32f10x_conf.h、stm32f10x_it.c、stm32f10x_it.h (此四个文件来自样板STM32F10x_StdPeriph_Template文件夹)、 startup_stm32f10x_md.s，

    \firmware\driver\src\所有.c文件

    进入项目配置页面，修改设置

    修改编辑器配置

  4. 遇到下图error，导入conf.h没有效果是因为未定义标记USE_STDPERIPH_DRIVER

    定义标记

  5. 无main则编写main即可，此时编译应该没有error
