可变与不可变对象

Python对象分为不可变对象和可变对象，这里的是否可变是指内存地址是否改变。可变对象可以修改，且内存位置不变；不可变对象无法更改，即变量值虽然发生变动但是内存地址已经变化，实际上是重新生成了一个变量，类似C语言中加了const修饰

  • 不可变对象：int(整形)、str(字符串)、float(浮点型)、tuple(元组)

  • 可变对象：list(列表)、dict(字典)、 set(集合）

python中赋值是在内存中建立一个对象（开辟一个空间）用于存放变量值，而变量名只是一个指向该对象的指针

局部变量和全局变量

  • 全局变量：在函数外作用的变量即上例中为 0 的 a 。

  • 局部变量：在函数中使用的变量即为 1 的 a ，只在函数内有效，可以在函数内通过global关键字将 a 设定为全局变量的 a ，global关键字只能将局部变量的 a 修改为全局变量的 a ，不可同时赋值。

python中函数的传递是参数的引用（类似传统的指针），而不是副本，即可以原地更新，节省内存

torch使用入门

torch.nn.module

torch.nn.Module 是 PyTorch 中所有神经网络模块的基类。它提供了一个通用的框架，用于构建和管理神经网络的各个组件。以下是 torch.nn.Module 的常规用法和作用的详细解释：

定义一个自定义模块

torch.nn.Module 的主要用途是定义自定义的神经网络模块。通过继承 torch.nn.Module，你可以构建自己的网络层、模型或模块。

初始化子模块

在 __init__ 方法中，你可以初始化子模块（如层、激活函数等）。这些子模块可以是 PyTorch 提供的标准层（如 nn.Linear、nn.Conv2d 等），也可以是其他自定义模块。

定义前向传播

forward 方法定义了模块的前向传播逻辑。它接收输入张量，并返回输出张量。在 forward 方法中，你可以调用子模块和其他操作来构建计算图。

参数管理

torch.nn.Module 自动管理参数（torch.nn.Parameter）。当你在 __init__ 方法中定义子模块时，这些子模块的参数会自动注册到父模块中。你可以通过 parameters() 方法访问所有参数。

模块的嵌套

torch.nn.Module 支持模块的嵌套。你可以将一个模块作为另一个模块的子模块，从而构建复杂的网络结构。

模块的状态管理

torch.nn.Module 提供了方法来管理模块的状态，例如：

  • train()：将模块设置为训练模式。
  • eval()：将模块设置为评估模式。
  • requires_grad_(True/False)：控制模块的参数是否需要计算梯度。

模块的移动

你可以将模块移动到不同的设备（如 GPU 或 CPU）。

模块的保存和加载

你可以保存和加载模块的状态字典（state_dict），从而实现模型的持久化。

模块的自定义操作

torch.nn.Module 还支持自定义操作，如自定义层、自定义激活函数等。

总结

torch.nn.Module 是 PyTorch 中构建神经网络的核心类。它提供了以下功能：

  • 定义自定义模块。
  • 初始化子模块。
  • 定义前向传播逻辑。
  • 自动管理参数。
  • 支持模块的嵌套。
  • 管理模块的状态（训练/评估模式）。
  • 将模块移动到不同设备。
  • 保存和加载模块的状态。
  • 支持自定义操作。

通过继承 torch.nn.Module，你可以构建各种复杂的神经网络模型，满足不同的需求。

1. 核心参数解析

(1) params

  • 类型: Iterable[torch.Tensor] 或 Iterable[dict]

  • 作用: 需要优化的模型参数，通常通过model.parameters()传递。

  • 示例:

    python

    复制

(2) lr (学习率)

  • 类型: float
  • 默认值: 1e-3
  • 作用: 控制参数更新的步长。
  • 调整策略:
    • 初始值通常设为 1e-3 到 1e-5，具体取决于任务复杂度。
    • 配合学习率调度器（如CosineAnnealingLR、ReduceLROnPlateau）动态调整。

(3) betas (动量系数)

  • 类型: Tuple[float, float]
  • 默认值: (0.9, 0.999)
  • 作用:
    • beta1: 控制一阶矩（梯度均值）的指数衰减率，类似动量。
    • beta2: 控制二阶矩（梯度平方均值）的指数衰减率，用于自适应学习率。
  • 调整策略:
    • 一般无需调整，保持默认值即可。
    • 若梯度噪声较大，可尝试减小beta1（如0.8）以加速收敛。

(4) eps (数值稳定性项)

  • 类型: float
  • 默认值: 1e-8
  • 作用: 防止分母为零的小常数，添加到二阶矩估计的分母中。
  • 调整策略: 通常无需调整，仅在极端数值问题时尝试修改（如1e-6）。

(5) weight_decay (权重衰减)

  • 类型: float
  • 默认值: 1e-2
  • 作用: 控制权重衰减（L2正则化的解耦形式）。
  • 关键区别:
    • AdamW vs Adam: AdamW将权重衰减与梯度更新分离，直接对参数进行衰减（而非通过梯度）。
  • 调整策略:
    • 常用范围 1e-2 到 1e-5，较大数据集可适当增大。
    • 若模型过拟合，尝试增大该值；若欠拟合则减小。

(6) amsgrad (AMSGrad变体)

  • 类型: bool
  • 默认值: False
  • 作用: 是否使用AMSGrad改进算法，避免二阶矩估计过早下降。
  • 调整策略:
    • 当训练不稳定或收敛困难时，启用amsgrad=True。
    • 可能略微增加内存和计算开销。

2. 进阶参数

(7) maximize (最大化目标)

  • 类型: bool
  • 默认值: False
  • 作用: 若设为True，优化器将尝试最大化目标函数（梯度上升）。
  • 应用场景: 强化学习中的奖励最大化。

(8) foreach (向量化加速)

  • 类型: bool
  • 默认值: None（自动选择）
  • 作用: 使用向量化操作加速参数更新，可能增加内存占用。
  • 调整策略:
    • 显存充足时设为True以加速训练。

(9) capturable (CUDA图捕获)

  • 类型: bool
  • 默认值: False
  • 作用: 支持在CUDA图中捕获优化器步骤，用于高性能计算优化。

(10) differentiable (可微分性)

  • 类型: bool
  • 默认值: False
  • 作用: 允许优化器步骤参与自动微分（如二阶导数计算）。
  • 应用场景: 元学习、优化器内循环。

3. 参数调优建议

参数 典型范围/值 调整优先级 说明
lr 1e-5 到 1e-3 高 配合学习率调度器动态调整
betas (0.9, 0.999) 低 一般无需调整
weight_decay 1e-5 到 1e-2 中 根据过拟合程度调整
amsgrad False 或 True 中 训练不稳定时启用
eps 1e-8 低 保持默认

argparse 参数包

参数名和类型

位置参数 parser.add_argument("argname") 使用python命令调用时，不需要额外参数

  • python file.py argvalue

关键字参数 parser.add_argument("--argname") 使用python命令调用时，需要添加额外参数—argname

  • python file.py --argname argvalue

短选项 parser.add_argument("-x", "--argname") 使用python命令调用时，需要添加短参数-x（x可以是其他单词）

  • python file.py -x argvalue

设置参数 parser.add_argument

action

  • 作用：指定参数触发时的动作。

    • store_true/store_false：参数存在时设为 True/False。

    • store_const：存储 const 指定的常量。

    • append：多次使用参数时，值追加到列表。

    • count：统计参数出现的次数。

    • version：打印版本信息并退出（需配合 version 参数）。

type

  • 作用：将输入值转换为指定类型（如 int, float, 或自定义函数）。

default

  • 作用：参数未提供时的默认值。

help

  • 作用：参数的帮助信息（显示在 --help 中）。

required

  • 作用：仅对可选参数有效，设为 True 时强制用户必须提供该参数。

dest

  • 作用：自定义解析后结果的属性名称。

choices

  • 作用：限制参数的允许值。

nargs

  • 作用：指定参数接收值的数量。

    • N：固定数量（如 nargs=3 需要 3 个值）。

    • ?：0 或 1 个值（常配合 default 和 const 使用）。

    • *：0 或多个值（列表形式）。

    • +：1 或多个值（类似 *，但至少一个）。

metavar

  • 作用：在帮助信息中显示参数名称（默认用大写参数名）。

const

  • 作用：配合 action="store_const" 或 nargs="?" 使用，指定常量值。
