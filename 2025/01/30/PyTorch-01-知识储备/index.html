文字定义

标量：仅包含一个数值被称为标量

向量：用标量组成的列表，这些标量值被称为元素(element)或分量（component）

张量（tensor）：n维数组。

  • 与NumPy相比，张量类支持自动微分，支持GPU。
  • 张量类在MXNet中为ndarray，在PyTorch和TensorFlow中为Tensor
  • 张量中每个值称为张量的元素（element）

  • 张量多用大写字母表示

  • PyTorch中同形状张量可以通过运算符（+，-，，/，*~求幂~，==，<=，……）直接处理

  • PyTorch中不同形状张量可以通过广播机制来执行按元素操作

    • 先拓展一个或两个数组使其形状相同，再执行操作

  • 访问张量时索引与切片可以使用

卷积相关

上采样

上采样（upsampling），又叫放大图像、图像插值(interpolating)，主要目的是放大原图像，从而可以显示在更高分辨率的显示设备上。上采样有3种常见的方法：双线性插值(bilinear)，反卷积(Transposed Convolution)，反池化(Unpooling)。

  • 优点：上采样可以恢复图像的细节信息，提高模型对局部特征的捕捉能力。
  • 缺点：某些方法（如转置卷积）可能导致计算量增加，甚至出现梯度消失的问题。

下采样

下采样（subsampled）或降采样（downsampled）或者称为缩小图像，它的主要目的有两个：

  • 使得图像符合显示区域的大小。
  • 生成对应图像的缩略图。

下采样一般为池化操作。池化最直观的作用便是降维，常见的池化有最大池化、平均池化和随机池化；池化层不需要训练参数。

::: tips

X = torch.tensor(列表) 将数据结构转换成张量

X = torch.arange(12, dtype = torch.float32, requires_grad = True, shuffle = True) arange创建一个行向量 X 。这个行向量为0-11，可指定类型为浮点数，requires_grad 是否加入计算图，shuffle 是否打乱生成的张量。

X = torch.zeros((高,长,宽), dtype = torch.float32) 构建全0张量

X = torch.ones((高,长,宽), dtype = torch.float32) 构建全1张量

X = torch.randn(高,长,宽) 在标准高斯分布中随机采样

X = torch.rand(高,长,宽) 在（0, 1）随机生成张量参数形状的张量

X = torch.zeros_like(Y) 构造一个与张量Y形状相同的张量Z，元素皆为0

X = Y.clone() 将A的一个副本分配给B

X = torch.normal(mean, std, size, generator=None, out=None) 该函数返回从单独的正态分布中提取的随机数的张量，该正态分布的均值是mean，标准差是std。用法如下：我们从一个标准正态分布N～(0,1)，提取一个2x2的矩阵：torch.normal(mean=0.,std=1.,size=(2,2))。我们也可以让每一个值服从不同的正态分布，我们还是生成2x2的矩阵：torch.normal(mean=torch.arange(4.),std=torch.arange(1.,0.6,-0.1)).reshape(2,2)

:::

可变与不可变对象

Python对象分为不可变对象和可变对象，这里的是否可变是指内存地址是否改变。可变对象可以修改，且内存位置不变；不可变对象无法更改，即变量值虽然发生变动但是内存地址已经变化，实际上是重新生成了一个变量，类似C语言中加了const修饰

  • 不可变对象：int(整形)、str(字符串)、float(浮点型)、tuple(元组)

  • 可变对象：list(列表)、dict(字典)、 set(集合）

python中赋值是在内存中建立一个对象（开辟一个空间）用于存放变量值，而变量名只是一个指向该对象的指针

局部变量和全局变量

  • 全局变量：在函数外作用的变量即上例中为 0 的 a 。

  • 局部变量：在函数中使用的变量即为 1 的 a ，只在函数内有效，可以在函数内通过global关键字将 a 设定为全局变量的 a ，global关键字只能将局部变量的 a 修改为全局变量的 a ，不可同时赋值。

python中函数的传递是参数的引用（类似传统的指针），而不是副本，即可以原地更新，节省内存

:::

函数传参

设置默认值的形参：形参名 = 默认值

如果在定义函数时为参数设置了默认值，那么在调用函数时可以不给该参数传值，此情况下将会使用默认值。

传递参数有两种方式：位置参数、关键字参数

  • 位置参数：fanc(argu_1,argu_2)，按照位置先后传递参数到形参
  • 关键字参数：fanc(argu_1 = '', argu_2 = '')，按照形参名传递参数到形参，需注意关键字参数必须要在位置参数后面
