Pytorch配置(包括cuda,cudnn)

  • cmd中输入nvidia-smi检查是否有gpu，以及支持的cuda版本

  • cuda的官方下载地址：https://developer.nvidia.com/cuda-toolkit-archive

    • cmd输入nvcc -V可以查看是否安装成功

  • cudnn的官方下载地址：https://developer.nvidia.com/rdp/cudnn-archive

    • 在cmd进入cuda的安装路径

  • Pytorch本身的准备：（注意torch要是gpu版本的，不能是cpu版的）

    pip3 install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu118

  • 确认是否可以正常使用GPU训练模型
